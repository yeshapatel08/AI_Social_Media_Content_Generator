# 🚀 AI Social Media Content Generator using Google Gemini

An AI-powered social media content generator built with **Python** and the **Google Gemini API**. This project helps create engaging, platform-specific content for social media, including LinkedIn posts, Instagram captions, hashtags, weekly content calendars, call-to-actions, AI-generated images, and image analysis—all from a single interactive Google Colab notebook.

This project was built as part of my learning journey in **Generative AI**, **Prompt Engineering**, and **Python**, with the goal of understanding how Large Language Models can be used to automate real-world content creation tasks.

---

## ✨ Features

- 📝 Generate professional LinkedIn posts
- 📸 Create engaging Instagram captions
- 🔖 Suggest relevant hashtags
- 📅 Generate weekly social media content calendars
- 📢 Create effective Call-to-Action (CTA) suggestions
- ✍️ Improve and rewrite existing content
- 🎨 Generate AI images using Google Gemini
- 🖼️ Analyze AI-generated images using Gemini Vision
- 💬 Interactive user inputs for personalized content generation

## 🚀 Getting Started

### Prerequisites

- Python
- Google Account
- Google Colab
- Gemini API Key

### Installation

1. Clone this repository.

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/AI-Social-Media-Content-Generator.git
```

2. Open the notebook in Google Colab.

3. Create a Gemini API Key.

4. Store the API Key securely using **Colab Secrets**.

5. Run the notebook from top to bottom.

---

## ▶️ How to Use

1. Open the notebook in Google Colab.
2. Enter the required information when prompted.
3. Choose the type of content you want to generate.
4. Let Gemini generate the content.
5. Review and refine the generated output.
6. Generate AI images if needed.
7. Analyze generated images using Gemini Vision.
